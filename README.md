# Purpose Built Endurance — MVP Website

Single-page static website for Purpose Built Endurance.

## Local preview
Open `index.html` in a browser, or serve the folder with any simple static server.

## Current behavior
- Sticky navigation with smooth scrolling
- Responsive desktop/tablet/mobile layout
- Coaching-plan CTAs auto-select the correct value in the contact form
- Original user photos are used directly (no AI-rendered faces)
- Contact form UI is complete but is not connected to an email/form backend yet

## Before launch
1. Connect the contact form to a form provider or serverless endpoint.
2. Add final business email and any social links if desired.
3. Push this folder to GitHub.
4. Connect the GitHub repo to Cloudflare Pages.
5. Point the Squarespace-managed domain DNS to Cloudflare.
